# Struttura, stile e comportamento

## Struttura (1-2 settimane)
### Modulo 0:
- Strumenti: VS Code, estensione Live Server, DevTools del browser
- Struttura di un progetto web (cartelle, file, convenzioni di naming)
- Come funziona il browser: richiesta, rendering, DOM (panoramica concettuale)
Letture utili:
[Come nasce un sito web](https://www.emmemedia.com/webmarketing/come-nasce-un-sito-web-scopriamo-insieme-le-fasi-di-creazione/)

### Modulo 1 - prima parte:

- Sintassi, tag, attributi, elementi vuoti
- Struttura base: doctype, html, head, body, meta tag (charset, viewport)
- Testo: titoli, paragrafi, liste, link, immagini
- Esercitazione: pagina statica personale (bio/CV)

### Modulo 1 - seconda parte:

- HTML semantico: header, nav, main, section, article, aside, footer
- Tabelle (uso corretto, non per layout)
- Form: input, select, textarea, label, attributi di validazione nativa (required, pattern, type=email)
- Accessibilità di base (alt, label associate, gerarchia titoli) e cenni SEO
- Esercitazione: form di contatto/registrazione (struttura, senza stile)

## Stile (3-4 settimane)

### Modulo 2 - prima parte:
- Sintassi CSS, selettori (elemento, classe, id, discendenza, pseudo-classi)
- Collegamento CSS (inline, interno, esterno) e cascata/specificità
- Box model, unità di misura (px, %, em, rem)
- Colori, tipografia, spaziature
- Esercitazione: stile della pagina statica del modulo 1

### Modulo 2 - seconda parte:
- Flexbox (concetti e proprietà principali)
- Grid layout (concetti base)
- Responsive design: media query, mobile-first
- Pseudo-elementi e piccole animazioni/transizioni (cenni)
- Esercitazione: rendere responsive il form di contatto, layout con flexbox/grid

## Comportamento (5-7 settimane)

### Modulo 3 - prima parte:
- Sintassi, variabili (let/const), tipi di dato, operatori
- Strutture di controllo (if/else, cicli)
- Funzioni (dichiarazione, arrow function)
- Array e oggetti, metodi principali (map, filter, forEach)

### Modulo 3 - seconda parte:
- Selezione elementi DOM (querySelector, ecc.)
- Modifica contenuto/stile via JS
- Event listener (click, submit, input)
- Validazione form lato client (collegandosi al form HTML/CSS già creato)
- Esercitazione: form con validazione JS e feedback visivo

### Modulo 3 - terza parte:
- Template literals, destructuring, spread/rest
- Introduzione asincronia: fetch() e JSON (anche solo verso un'API pubblica gratuita)
- Gestione errori base (try/catch)
- Collegamento concettuale al backend (PHP/DB) se previsto nel programma
- Esercitazione: piccola chiamata fetch che popola la pagina con dati esterni

# Progetto finale integrato (1 settimana):

- Consolidamento: gli studenti completano un progetto che unisce HTML semantico + CSS responsive + JS con validazione e/o fetch (es. form di registrazione completo, mini-dashboard, o pagina con dati caricati dinamicamente)
- Presentazione/discussione dei progetti, debugging guidato
